# Version history, newest first. A line that does not start with "- " opens a version: the version
# number, then an optional name. A version without items is listed nowhere. The mod shows the history
# in game; tools\build.ps1 writes it into the Workshop description and the release notes.

1.5.1

1.5.0
- 翻譯 11/7 遊戲更新新增與修改的文字（盧、艾琳諾保釋、塞爾皮科結局等新劇情，模組管理畫面與新選項）。
- 模組屬性 Performance 改譯「性能」、Efficiency 改譯「能效」（原為「效能」「效率」）。
- 手寫字型改用毛筆風格的莫大毛筆 Bakudai，取代霞鶩文楷，更接近原版的毛筆字。
- 新增簡體護欄：遊戲更新後還沒翻譯的新文字、程式組出來的文字與舊存檔內容，在顯示前自動轉成正體，不再冒出簡體字。精校譯文不受影響。
- 跟著官方簡中統一用語：Access Card 改為「鑰匙卡」、快遞員改為「送貨員」、藥商改為「藥劑師」。

1.4.1
- 客人 Thief 改譯「竊賊」、Petty Thief 改譯「小偷」（原為「扒手」）。
- 打給奧丁時的回答「說。」改為「對。」。

1.4.0 好讀更新
- 內文改用較粗的源樣黑體 Medium，小字更清楚。
- 太小的內文（入門指南、對話、掃描器等）在框內有空間時自動放大；標題與按鈕字也略為放大。
- 拿掉中文段落開頭對不齊的半形空格；報紙改為統一縮排兩個全形空格。修正物品說明裡多出的空格與空行。
- 水質掃描器、成分光譜儀與水質檢驗試紙的結果改成「檢驗結果／品名 純度」與「[標籤] 品名」，字可以放得更大。
- 品名拿掉開頭的數量詞（如「一捲衛生紙」改為「捲筒衛生紙」、「一瓶淨水錠」改為「瓶裝淨水錠」），委託不再顯示成「4 一捲衛生紙」。
- 「檢測」統一改為「檢驗」。

1.3.2
- 修正水有時整批賣不出去的問題（換過語言或沿用舊存檔時）。
- 語言選單的 Simplified Chinese 直接改為「正體中文」，不再並列簡繁兩個選項。
- 翻譯 10/31 遊戲更新新增與修改的文字。
- 客人對店主的稱呼改為不分性別（「老兄」「小子」改為「老闆」「年輕人」等）。
- 3D 印表機說明的品質係數依英文原文改為 0.25（官方簡中誤植為 0.5）。
- 水耕農場主開局的第二台機器改顯示「破舊水耕系統」（原本是程式寫死的英文 Decrepit Hydroponic System，只影響新開的存檔）。

1.3.0
- 全部譯文精校完成；語言選單新增「正體中文」，可與原版簡體中文隨時切換。

1.2.0
